# .github de Magnore

Plantillas de issue por defecto para todos los repositorios de la organización `magnore`.

GitHub las usa en cualquier repo que no tenga su propia carpeta `.github/ISSUE_TEMPLATE`.

- `ISSUE_TEMPLATE/01-incidencia.yml`: comunicar una incidencia
- `ISSUE_TEMPLATE/02-mejora.yml`: proponer una mejora
- `ISSUE_TEMPLATE/03-peticion-cliente.yml`: registrar una petición de cliente
- `ISSUE_TEMPLATE/config.yml`: desactiva las issues en blanco

Este repositorio es público: no guardes aquí código, credenciales ni datos de clientes.
